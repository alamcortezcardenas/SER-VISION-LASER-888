## 🚀 Descripción del Proyecto
El **SER-01** es un nodo de interacción fotónica vestible que integra una lente de **Moissanita** para la gestión de energía láser. Este repositorio contiene la arquitectura del **Nexo Digital**, permitiendo la sincronización entre visión computacional (smartphone) y actuadores físicos (brazalete).

## 🔱 Innovaciones Integradas
* **Sincronización AR:** Alineación en tiempo real del haz láser con la cámara del dispositivo móvil.
* **Protocolo Li-Fi:** Transmisión de datos punto a punto mediante pulsos lumínicos.
* **Gimbal Control:** Lógica de movimiento para el balero de dirección ajustable.

## 📁 Estructura del Proyecto
- `/software`: Código Python para el ESP32 y lógica de la App.
- `/hardware`: Planos técnicos y esquemas de circuitos.
- `/docs`: Manifiesto de Resonancia y especificaciones de logística.
